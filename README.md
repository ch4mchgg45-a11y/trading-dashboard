# Trading Dashboard (dati pubblici, sola lettura)

Pagina di sola visualizzazione per il sistema di trading. Contiene
esclusivamente numeri aggregati (capitale virtuale, operazioni,
percentuali di successo) generati automaticamente dal repository
privato del progetto. **Nessuna credenziale, chiave API o dato
personale è presente in questo repository.**

Aggiornato automaticamente ogni ~30 minuti.
